Visual Lab

Change one physical parameter and watch the graph move. Each plot is computed in this browser from the displayed model. Values are illustrative teaching models, not measurements from a particular processor.

01 · Latency vs hit rate

RAM is a slow fallback. Better hit rate reduces average access time.

AMAT = L1 latency + miss rate × RAM latency.

02 · Memory hierarchy staircase

As a working set grows beyond each cache, average access time rises.

Working set is the actively reused data. The steps mark capacity boundaries in this simplified model.

03 · Cache line size trade-off

Larger lines can capture nearby data, but can waste space when access is scattered.

The plotted miss rate is a teaching model, not a universal workload prediction.

04 · Hit rate changes the budget

Compare a cache with the same access latency but different miss rates.

05 · Traversal visualiser

Watch the same 16 × 16 array visited in two different orders. Each element is 4 bytes and each cache line is 64 bytes. This demo uses a four-line LRU cache.

Green = cache hit; red = cache miss; amber outline = current element. Every displayed cell is a 4-byte integer.

06 · Address anatomy

Set and byte offsets are taken from the lower address bits when sizes are powers of two.
